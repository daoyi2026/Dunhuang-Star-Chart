# Dunhuang Star Chart

Fullscreen p5.js interactive Dunhuang-inspired star chart with an original generative ambient soundtrack.

## GitHub Pages
1. Settings → Pages
2. Build and deployment → Source: Deploy from a branch
3. Branch: main / /(root)
4. Save

Expected URL: https://daoyi2026.github.io/Dunhuang-Star-Chart/

The soundtrack is generated in-browser with Web Audio API and starts only after clicking “听星河”.
