# 敦煌星图 · 天极版 (preview-v8)

把整个文件夹放进仓库根目录，GitHub Pages 地址即为 `/Dunhuang-Star-Chart/preview-v8/`。
若要替换首页，把这五个文件复制到仓库根目录覆盖 `index.html`，旧的 `sketch.js`、`ui.js`、`music.js`、`style.css` 可删除。

## 视图
- **唐时**（默认）：以公元 700 年的天极为中心的星图，星空缓缓旋转。
- **此刻敦煌**：站在敦煌（北纬 40.14°，东经 94.66°）面朝正北看到的此刻真实天空，地平线、远山与沙丘剪影，天色向地平线渐亮。切换时星空先经历约 1300 年的岁差漂移，再由星图视角过渡为站立视角。
- **古卷**：在星空空白处长按约 0.8 秒（或点右上角「古卷」），打开敦煌星图原件紫微宫部分的高清图，可滚轮或双指缩放、拖动查看，点暗处或按 Esc 回到星空。
- **入宫导览**：九站，自天极至天牢，每站约 11 秒，可用 ← → 换站。

## 文件
- `sky-data.js`：约 1.4 万颗恒星（≤7.2 等）、261 组中国星官连线、银河亮度轮廓，J2000 坐标，取自 d3-celestial（HYG/Hipparcos）。
- `texts.js`：原项目 28 个星官的释义与出处（从原 sketch.js 提取，未改动）。
- `dunhuang-ziwei.jpg`：敦煌星图（大英图书馆 Or.8210/S.3326）紫微宫部分，图片来自 Wikimedia Commons，公有领域。
- `app.js`：Canvas 2D 渲染，无第三方依赖。银河颗粒按真实轮廓采样，岁差与地平坐标在页面中实时计算。
- `audio.js`：Web Audio 生成的环境音，点「听星河」开启。
